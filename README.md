# MarketLens AI Bio Page

A standalone premium bio / landing page for MarketLens AI.

## Files
- `index.html` — page structure and copy
- `style.css` — crimson/gold visual system, glassmorphism, responsive layout, animations
- `script.js` — reveal animations, smooth scrolling, pointer glow, hero card interaction

## Launch
Open `index.html` directly in a browser, or deploy the folder to GitHub Pages / Netlify.

## Main app
https://marketlensai.ai.studio/
